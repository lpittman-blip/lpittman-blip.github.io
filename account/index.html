Artemis Chat

Artemis Chat is a private conversation at /chat. Replies stream in while they are written. You can search history, rename or archive a thread, edit a message without losing the earlier branch, and export the conversation as Markdown or JSON. Web search is described on the site as currently via Wikipedia, along with reading a public web page, when those tools are on.

Account required. Chat is currently answered by a labelled bootstrap model while Artemis's own model is trained.

Artemis CLI

Artemis CLI is a terminal coding agent for developers, by request. It finds context in a repository with glob, grep, and ranged file reads instead of a vector database. artemis serve runs a local API on port 7777, with OpenAPI docs at /docs. Login defaults to api.artemisai-bycutlineindustries.studio.

Available to developers by request.

Your account

Your space with Artemis.

Create an account or sign in with email and password. Conversations are private to that account and can be opened on another device. You can export a conversation as Markdown or JSON, export the account as JSON, and choose whether inactive conversations are kept until you delete them or removed after 30, 90, or 365 inactive days. Deleting a conversation removes its live database records. Hosting backups follow a separate expiry policy.

Conversations are private to your account. Export or delete them any time.
