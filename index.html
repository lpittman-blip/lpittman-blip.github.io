What Artemis Chat does today

Artemis Chat is a signed-in conversation in your browser. You type a message, the reply streams back while it is written, and the thread is saved to your account so you can open it again on another device. You can search that history, rename a conversation, archive it, or delete its live database records. Editing a message keeps the earlier branch. You can copy an answer, mark it helpful or not helpful, or ask Artemis to try again.

What you can do with it

These are the jobs the chat workspace already offers. The live status card further down shows which gateway tools are on right now, because search, page reading, voice input, and file upload are reported by the API rather than promised as always available.

In Chat

Write and explain code

Ask Artemis to write a function, explain a snippet, or change code you paste in. Answers can include fenced code blocks you can copy. The Code tab collects code from the answer and any Python a tool actually ran, with its output. The starter prompts in an empty chat include writing a Python function and calculating with Python.

When the tool is on

Research a question

The site describes web search as currently via Wikipedia, plus reading a public web page. When a tool returns sources, Chat lists up to five of them under the tool step. The status card shows whether web search and page reading are on in the gateway you are visiting, and which search provider it reports.

In the browser

Listen, or dictate

Read aloud uses your browser’s speech synthesis. The voice picker lists those voices, and the orb pulses while Artemis is speaking. Dictation appears only when the browser provides speech recognition, and it fills the message box. It is not a stored recording. Account settings say raw audio recording and file uploads are not enabled.

Saved to you

Keep the thread

Conversations are saved on your account, not only in the tab you have open. The browser keeps a draft of what you are typing. You can search past chats, export them, and pick them up after you sign in on another device. The composer reminds you to check important answers.

Meet Artemis

The ring on this page is the Artemis orb, the same mark that sits with a conversation in Chat. It is drawn as particles on a light page. While a reply is read aloud, the ring pulses with that voice. If you would rather it stay still, Pause motion in the footer stops the animation, and the page also respects a reduced-motion setting from your device.

Voices default to the ones built into the browser you already have. You can preview a line, choose a voice, and set replies to be read automatically when they finish. Pause, resume, and stop are in the voice controls under the message box. A hosted voice service is possible only through a server endpoint configured for the page. This site never puts a voice-service key in the browser, and these pages do not set that endpoint, so a visit uses browser speech.

Chat itself runs at /chat on desktop and on a phone. There is no separate app described on this site. Sign-in, sign-up, and login addresses all bring you to the account page.

How an answer is described, and what is answering now

The pages describe the design of Artemis’s own model, which is still in training, as one orchestrator and a set of specialists. Artemis reads the request and hands each specialist a focused piece. Saturn is described for code, Neptune for research, Uranus for math, Mercury for memory, and Pluto for system design, with Venus checking the other work for errors and unsupported claims before one reply is written. The names used for that design are Artemis, Venus, Saturn, Pluto, Neptune, Uranus, Mercury, Mars, Apollo, Jupiter, and Earth.

That description is the design, not a claim about the weights answering Chat today. Chat runs on a labelled bootstrap model, which the app distinguishes from Artemis’s own weights. A model menu appears in Chat only when the gateway reports more than one model it can serve. The default stays Artemis.

A separate design rule is stated for Artemis’s own model: it does not send your request to someone else’s AI model. That rule is meant for teams that cannot send their code to a third-party model provider. It is stated for Artemis’s own model, which is not the bootstrap model in Chat today.

Privacy and your account

Conversations are private to the account you sign in with. They are saved through the Artemis gateway, and the site states that they are not automatically used to train Artemis. The browser stores drafts of unsent text for that account. It does not keep the conversation log or your password there.

From account settings you can export the open conversation as Markdown or JSON, export the whole account as JSON, and set retention: keep conversations until you delete them, or delete them after 30, 90, or 365 inactive days. Deleting a conversation removes live database records. The same screen says hosting backups require a separate expiry policy, so a delete is not described as wiping every backup.

That screen also says raw audio recording and file uploads are not enabled. The composer tells you to check important answers. Sign-out is in the same account dialog.

Questions the site can already answer

Do I need an account?

Yes. Chat asks you to sign in before a conversation is saved. You use an email and a password. Creating an account requires a password of at least 12 characters. The addresses /login, /sign-in, and /sign-up all send you to the account page.

Which model is answering?

Chat is answered by a labelled bootstrap model while Artemis’s own model is still being trained. The app says when the answer is not from Artemis’s own weights. The status card on this page reads that from the gateway in your browser. A second model shows up in the menu only if the gateway says it can serve it.

Are my chats used to train Artemis?

The site states that conversations are not automatically used to train Artemis. It does not describe any other training use.

Can I export or delete a chat?

Yes. You can export one conversation as Markdown or JSON, export the account as JSON, and delete a conversation’s live database records. You can also set a retention period. Hosting backups are called out as a separate expiry policy.

Can I upload a file or have Artemis call me?

Account settings say file uploads and raw audio recording are not enabled. The status card will say “Not yet” for file upload and voice input when the gateway reports them off. Dictation, when your browser supports it, only fills the text box. Read-aloud plays in the browser. It is not a phone call.

Where do I get the CLI or the API?

Both are by request. The CLI is a terminal agent: glob, grep, and ranged file reads, plus artemis serve on port 7777 with docs at /docs. The API is streaming chat, an OpenAI-compatible chat completions endpoint, per-account memory, and server-side keys. Write to support@artemisai-bycutlineindustries.studio.
